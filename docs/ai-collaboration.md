# AI 协作开发说明（这个项目是怎么和 AI 一起做出来的）

> 本文记录本项目的**人机分工与验证纪律**。结论先写：AI 负责实现，人负责定义问题、定验收、
> 验收与发布；AI 的任何自述都不作为验收依据，只看复跑结果。

## 1. 分工

| 角色 | 谁 | 具体做什么 |
|---|---|---|
| 需求与设计 | 人 | 判断面试方真正考什么、定数据源矩阵、定降级口径、定交付物 |
| 实现 | AI 编码代理（CLI） | 写代码、写测试、写文档、跑真实抓取取证 |
| 验收 | 人 | 独立复跑全部命令、扫过拟合与临时放行、检查证据与声明是否一致 |
| 增量修复 | AI 编码代理 | 按验收反馈做定向修复，不改无关代码 |

时间开销：实现轮约 30 分钟，增量修复轮约 15 分钟；两个轮次都是先落可运行骨架，再横向扩。

## 2. 任务书怎么写（这是质量的源头）

给 AI 的不是"帮我写个抓取系统"，而是一份**可验收的任务书**，四段结构：

1. **硬需求**：编号 R1..R10，每条都能被一条命令验证（例：期刊名单必须来自运行期配置，
   不得写死在代码里；禁止引入 Flask/Gradio）。
2. **数据源矩阵 + 已验证事实**：派活前先自己探测连通性，把"哪个源可达、哪个源覆盖差"写进任务书。
   例：中文刊在 Crossref 里覆盖极差（实测某刊最新只到 2014 年且无摘要），
   因此任务书写明"国内刊不许只靠 Crossref""CNKI 实测返回空，不许当主路径"。
3. **HOWTO（节奏）**：前 3 分钟必须落盘骨架、**每 5 分钟至少一次可见产出**、先打通一条端到端链路再横向扩。
   —— 这条是被事故教训逼出来的：只给验收清单会让模型把整份实现在推理里推演完才动手，
   实测出现过"读完任务书 8 分钟、零文件落盘"。
4. **禁止事项**：不许为通过测试写死白名单/逐条 if；不许留 `or True`、注释掉的守卫；
   不许把"单元测试全绿"当成"现场可用"；任何失败都必须显式报出，不许静默降级。

## 3. 验收怎么做（不信自述）

- **独立复跑**：AI 交的每份证据脚本我都不直接用，而是自己按 README 的三条命令重建环境重跑
  （解压 → 新建虚拟环境 → 装依赖 → 跑 demo/pytest/smoke）。
- **证据对账**：`docs/source-evidence.md` 里每本刊都有真实 HTTP 状态、期号、发布日期与前 3 条标题；
  我按刊抽查是否与 fixtures 一致。
- **反过拟合扫描**：`grep` 检查用例原文是否被塞进代码、是否有白名单式特判。
- **降级必须可见**：语义后端不可用时要打印 `matcher=lexical (degraded: 原因)`；
  期刊级限制（如官网不公开摘要）也要在报告里列出来，不许悄悄用标题顶替摘要还称为"语义匹配"。
- **离线可复现**：把最近一期的真实响应存成 fixtures，验收时断网也能把整条链路复跑一遍。

## 4. 这一轮里真实发生过的三件事（一并记录，不粉饰）

1. **AI 收尾时清掉了自己的工作环境**：它把 `.venv`、pip 缓存、日志都当作临时产物清掉了，
   于是 `scripts/smoke.sh` 退到系统 Python 上跑，出现 5 项 FAIL。
   代码没问题，是环境没了 —— 我按 README 三步重建后复验全绿。
   教训：AI 的"清理"要写进交付说明，交付态必须是**干净可重建**，而不是"我这儿跑过"。
2. **验收查出一个真缺陷**：`resolve` 只认配置内的期刊，配置外期刊直接返回"不存在"。
   而本系统的前提是"期刊名现场公布"，这等于核心场景不可用 → 追加一轮增量：
   在线解析链（Crossref /journals 查询 + OpenAlex 兜底）、`--append-config` 追加配置、
   真实联网证据与新增测试（测试数只增不减：12 → 20）。
   中文刊解析不到是**已知边界**，如实打印失败原因，不伪造成功。
3. **打包软链的坑（人这边的失误）**：把仓库打成 zip 时软链被写成了目录，
   解压后 `python -m radar` 报 `No module named radar.__main__`、模型缓存变成空目录。
   修正后重打包复验；并在 README 里补了三条等价路径
   （`PYTHONPATH=src` / `pip install -e .` / 手工补软链），三条都实测过。

## 5. 边界与取舍

- 本仓库**不内置模型权重**（体积大且属于可再生成的缓存），首次运行按 README 从镜像拉取；
  没有权重时 matcher 会**显式降级**为词法后端，不会伪装成语义匹配。
- AI 生成的"报告数字"只能当线索：所有对外声明的数字（测试数、源连通性、耗时）
  都以我自己复跑的输出为准。
- 我保留了对 AI 产出的否决权：本轮就否决了"把 CNKI 当主路径"和"用词法分数冒充语义分数"两个选项。
